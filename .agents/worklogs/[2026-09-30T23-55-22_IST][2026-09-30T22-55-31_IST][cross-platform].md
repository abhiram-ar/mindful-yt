# Windows, macOS and Linux

ytget was Windows-only. It now builds and runs on all three, and picks its
tools per OS.

## Tools per OS

| | yt-dlp | JavaScript runtime | ffmpeg |
| --- | --- | --- | --- |
| Windows | `yt-dlp.exe` (`_arm64`, `_x86`) | Deno zip, or Node 22+ on PATH | winget `yt-dlp.FFmpeg` |
| macOS | `yt-dlp_macos` (universal) | Deno zip | `brew install ffmpeg` |
| Linux | `yt-dlp_linux` (`_aarch64`; `_musllinux` on musl) | Deno zip (glibc only) | apt-get, dnf `ffmpeg-free`, pacman, zypper or apk, via sudo |

- **yt-dlp and Deno:** ytget downloads them into its tools folder and checks
  their SHA-256 before anything runs or moves into place.
  - yt-dlp's checksums come from `SHA2-256SUMS` (`<hash>  <name>`).
  - Deno publishes one `.sha256sum` per zip. The macOS and Linux files are
    `<hash>  <name>`, but the Windows ones are PowerShell `Get-FileHash`
    output. `denoSum` takes the single 64-hex token.
- **ffmpeg:** the package-manager command is shown on screen and runs only
  after Enter, through `tea.ExecProcess`, so `sudo` can prompt. openSUSE has
  no package named exactly `ffmpeg`, but `ffmpeg-7` provides it.
- **How yt-dlp finds ytget's Deno:** `ytdlp.Command` puts yt-dlp's own folder
  first on its PATH. This avoids `--js-runtimes deno:<path>`, whose
  `RUNTIME:PATH` form is unclear with Windows drive letters.
- **Musl detection:** reads the `PT_INTERP` of `/bin/sh`. Glibc distros can
  have the musl loader installed too.

## Fixed after review

- **The proxy password moved off yt-dlp's command line** (Linux and macOS
  let any local user read it). It now goes in on stdin, via
  `--config-locations -`.
- **Closing the terminal now stops everything.** On Unix, SIGHUP cancels the
  app context, and the TUI exits through `tea.WithContext`. `main` then
  cancels and calls `ytdlp.Wait`, so no yt-dlp survives ytget. That wait also
  closes a race on Ctrl+C.
- **Unix `KillTree`** sends SIGTERM to the process group, then SIGKILL after
  3 s. PyInstaller removes its unpacked temp files only on a clean exit.
- **Tab and taskbar progress (OSC 9;4)** goes only to Windows Terminal, ConEmu,
  Ghostty 1.2+ and iTerm2 3.6.6+. Older iTerm2 treats it as a notification.

## Testing Linux here

WSL (Ubuntu 24.04) has no Go. Build test binaries on Windows and run them in
WSL:

```sh
GOOS=linux GOARCH=amd64 go test -c -o <dir>/<pkg>.test ./internal/<pkg>
GOOS=linux GOARCH=amd64 go test -c -tags live -o <dir>/ytdlp_live.test ./internal/ytdlp
```

Run the live tests with `YTGET_HOME` set to a folder under `/tmp`. WSL blocks
YouTube too (its `/etc/hosts` comes from Windows), so they exercise the proxy.

## Not verified

- **macOS:** it compiles, but was never run.
- **Linux ffmpeg install:** the command wasn't run, because it needs the
  user's sudo password. So the Linux download test skips.
- **Windows temp files:** `taskkill /F` on cancel can leave PyInstaller's
  `_MEI*` folder in `%TEMP%`.
