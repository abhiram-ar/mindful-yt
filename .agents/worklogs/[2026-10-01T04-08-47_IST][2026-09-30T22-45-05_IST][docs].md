# README, AGENTS.md and working with the user

## README

- **Keep it minimal and user-facing.** Development detail goes in AGENTS.md
  or a worklog.
- **The disclaimer is in the user's own words.** Fix typos only, and show any
  rewording before pushing.
- **Install commands are two lines each,** with the repo name in a `repo`
  variable, because the one-liners were about 110 characters and GitHub showed
  a horizontal scrollbar.
  - The `go install` line stays on one line: a `\` continuation breaks when
    pasted into PowerShell.

## AGENTS.md

The user wants it minimal: only what an agent needs, nothing added for its
own sake. Background goes in these worklogs, named
`[<last edited IST>][<first started IST>][<feature>].md`, and renamed on
every edit.



## Working with the user

- **Git:** commit and push only when asked. Stage files by name, and
  `git fetch` first, because the user commits too. Show which of their edits
  a commit includes.
- **Tokens:** never read or use the saved GitHub token. The repo is public,
  so read GitHub's state (releases, Actions runs) anonymously from
  api.github.com. For anything that needs an account, ask the user.
